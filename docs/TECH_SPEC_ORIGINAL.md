# Original Tech Spec (pre-spike)

> **Status:** archived placeholder. The original tech spec was drafted before the upstream TRIBE v2 API was inspected and contained several load-bearing inaccuracies (multi-GPU placement, separate image input path, `<2.1.0` numpy pin, etc.). It is not preserved verbatim in this repo.
>
> **Source of truth for what changed:** [`docs/SPIKE_FINDINGS.md`](./SPIKE_FINDINGS.md).
> **Current spec:** [`docs/TECH_SPEC.md`](./TECH_SPEC.md) (v2, 2026-05-11).
>
> If you are trying to understand a design decision, read both files in order: SPIKE_FINDINGS first, then TECH_SPEC v2. The ADRs under `docs/DECISIONS/` record specific choices.
